# ชุดทดสอบกับผู้ใช้ — ThalLink รุ่นเรียนรู้ภายในเครื่อง

สถานะ 15 ตุลาคม 2026: **เตรียมพร้อม ยังไม่มีผู้ทดสอบจริง** ตามที่ผู้ใช้แจ้ง ผลทดสอบอัตโนมัติอยู่ใน [TEST_RESULTS.md](TEST_RESULTS.md) และไม่แทนผลทดสอบในเอกสารนี้

ใช้เวลาโดยประมาณ 15–25 นาทีต่อคน แนะนำเริ่มด้วยผู้เรียนหนึ่งคนและผู้ที่ทบทวนผลแล็บหนึ่งคน ใช้ข้อมูลสมมติด้านล่างเท่านั้น ทดสอบในเครื่อง ไม่ต้องส่งไฟล์ผลตรวจผู้ป่วยหรือข้อมูลระบุตัวบุคคล

## เริ่มต้น

1. ดับเบิลคลิก `run.cmd` ในโฟลเดอร์โปรเจกต์ แล้วเปิด `http://127.0.0.1:8501` หรือใช้พอร์ตที่ระบุเมื่อเปิดแอป
2. เริ่มในแท็บใหม่ จดเบราว์เซอร์ รุ่น ระบบปฏิบัติการ ขนาดหน้าจอ และวันที่ทดสอบ
3. ผู้สังเกตการณ์อ่านโจทย์ทีละข้อ โดยยังไม่บอกตำแหน่งปุ่ม จดเวลา จุดที่ลังเล ความช่วยเหลือ และข้อความที่ไม่เข้าใจ
4. ใช้เมนูในแอปเพื่อเปลี่ยนหน้า การเก็บค่าร่างครอบคลุมเซสชันปัจจุบัน ไม่ใช่การบันทึกข้อมูลถาวรหลังปิดแท็บ/เริ่มเซสชันใหม่ เมื่อแก้ตัวเลขให้กด Tab หรือคลิกออกจากช่องเพื่อส่งค่าล่าสุด

## เกณฑ์ตรวจสำหรับผู้สังเกตการณ์

- **U01:** หาเม็ดเลือดขาวได้จากตัวเลือกแผนที่หรือเมนูกลุ่มงานเพิ่มเติม ภาพสามกรณีแสดงผลรวม 4, 6 และ 1 ตามลำดับ เส้นอ้างอิง WBC อยู่ที่ 4 ส่วนต่าง 3 ในกรณีข้อมูลไม่ครบไม่ได้อ้างว่าเป็นผลวัด กราฟไม่ได้สื่อว่าผลรวมเท่ากันหมายถึงผลปกติ
- **U02:** ALC คำนวณได้ 3; รวม ANC 3 + ALC 3 = 6 ซึ่งเกิน WBC 4 ต้องมีข้อผิดพลาดและสถานะข้อมูลไม่ถูกต้อง ไม่แสดงผลรวมเป็น 100% โดยซ่อนส่วนเกิน
- **U03:** หลังกลับหน้า CBC ค่าในช่องต้องเป็น 10.2 ส่วนผล/รายงานก่อนกดประเมินใหม่ยังอ้างอิง Hb 9.1 และเวลาเดิม หลังประเมินใหม่จึงเปลี่ยนเป็น 10.2 ค่าอื่นและแหล่งข้อมูลต้องไม่หาย
- **U04:** controls ยังเป็นผ่าน, tolerance ยังเป็น 41 และเซลล์ยังตรงกับค่าที่แก้ PCR แสดงผลสดตามตารางและ controls ปัจจุบัน จึงอัปเดตเมื่อแก้ไขและอาจมีเวลาประเมินใหม่เมื่อหน้า rerun ไม่มีปุ่มประเมินแยกแบบ CBC ตรวจว่ารายงานที่ดาวน์โหลดตรงกับค่าที่แสดงในขณะนั้น
- **U05:** JSON `report_schema_version` เป็น 2; `partner_screening` มี `complete`, `status`, `interpretation`, `recommendations`; `thresholds_used` เป็น object; มี `normalized`, `derived`, `input_origin`, `evaluated_at`, `ruleset_version`, `ruleset_hash` แหล่งข้อมูลตัวอย่างต้องเป็น `demo` CSV ต้องมีรายละเอียดคู่ครบ ดาวน์โหลดซ้ำโดยไม่ประเมินใหม่ต้องคงเวลาประเมินเดิม
- **U06:** ไม่ต้องเลื่อนแนวนอนทั้งหน้าเพื่อใช้ปุ่มหลัก (ตารางกว้างเลื่อนภายในได้) ข้อความและกราฟไม่ทับกัน อ่านคำเตือนได้ทั้งสองธีม โฟกัสมองเห็นและควบคุมตัวเลือกหลักด้วยแป้นพิมพ์ได้ ตรวจด้วยเบราว์เซอร์จริง ไม่ใช้ AppTest ตัดสินข้อนี้

การเห็นคำเตือนอื่นจากข้อมูลที่ยังไม่ครบในโจทย์ถือว่าเป็นไปได้ ให้จดข้อความจริง อย่าปิดข้อผิดพลาดว่า “ผ่าน” เพียงเพราะตรงกับตัวอย่างหนึ่งส่วน

## บันทึกปัญหาและทดสอบซ้ำ

แต่ละปัญหาให้ระบุรหัส, ขั้นตอนทำซ้ำ, ค่าที่กรอก, ผลที่คาด, ผลจริง, ความถี่, ขนาดหน้าจอ และหลักฐานที่ไม่มีข้อมูลส่วนบุคคล จัดลำดับผลรวม/ผลวิเคราะห์ผิด → ข้อมูลหายหรือรายงานไม่ตรง → ใช้งานไม่ได้ → ความชัดเจน/ความสวยงาม

หลังแก้ให้ผู้ทดสอบทำโจทย์เดิมซ้ำและบันทึกผลใหม่ พร้อมทดสอบงานข้างเคียงที่อาจได้รับผลกระทบ ยังไม่ปิดการทดสอบรับงานจน U02–U05 ผ่านและปัญหาที่ทำให้ใช้งานต่อไม่ได้ได้รับการแก้ ทุกช่องที่ยังไม่ได้ลองต้องคงสถานะ “ยังไม่ได้ทดสอบ”

ชุดนี้ตรวจประสบการณ์ใช้งานและความสอดคล้องของซอฟต์แวร์ ไม่ใช่การรับรองความแม่นยำทางคลินิกหรือการอนุมัติกฎตาม SOP
