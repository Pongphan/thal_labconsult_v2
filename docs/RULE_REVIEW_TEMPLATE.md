# แบบบันทึกทบทวนกฎและกรณีศึกษา

สถานะเริ่มต้น: **ยังไม่ทบทวน** แบบฟอร์มนี้ช่วยบันทึกหลักฐาน ไม่ใช่ใบรับรองและไม่เปลี่ยนสถานะกฎในโปรแกรม การใช้งานรุ่นปัจจุบันจำกัดการเรียนรู้และทบทวนภายในเครื่อง

## ข้อมูลการเปลี่ยนแปลง

| รายการ | ผู้ทบทวนกรอก |
|---|---|
| โมดูล / rule IDs / ไฟล์ | |
| เวอร์ชันเดิม → ใหม่ / SHA-256 | |

## สิ่งที่ต้องตรวจ

- [ ] ระบุขอบเขตที่ใช้ได้และกรณีที่ยังใช้ไม่ได้
- [ ] ความหมาย input และหน่วยสอดคล้องกับวิธีตรวจ; ไม่ใช้ช่วง validation แทนช่วงอ้างอิง
- [ ] แยก unknown / ไม่ได้ตรวจ / ผลลบ / ศูนย์ และจัดการข้อมูลขัดแย้งอย่างชัดเจน
- [ ] ทดสอบค่าต่ำกว่า / เท่ากับ / สูงกว่าจุดตัด รวมอายุและบริบทที่เปลี่ยนเงื่อนไข
- [ ] ข้อมูลผิดหรือขาดไม่กลบข้อเตือนจากข้อมูลอื่นที่ใช้ได้
- [ ] รายบุคคล / CSV / กราฟ / รายงาน ใช้ข้อมูลและเกณฑ์ชุดเดียวกัน
- [ ] ข้อความ แหล่งอ้างอิง ตัวอย่างสมมติ และคำอธิบายคะแนนไม่มีข้ออ้างเกินหลักฐาน
- [ ] เพิ่ม regression cases ที่ไม่อาศัย engine คำนวณ expected result ให้ตัวเอง
- [ ] บันทึกผลทดสอบซอฟต์แวร์และผลทบทวนเนื้อหาแยกกัน

## บันทึกกรณีที่ทบทวน

ใช้รหัสสมมติ ห้ามใส่ชื่อ HN หรือข้อมูลระบุตัวบุคคลใน repository

| รหัสกรณี | input / บริบท | ผลที่คาดหวังโดยผู้ทบทวน | เหตุผล / แหล่งอ้างอิง | ผลจากโปรแกรม | ตรงกัน / งานค้าง |
|---|---|---|---|---|---|
| | | | | | |

## ข้อสรุปการทบทวน

เลือกสถานะพร้อมเหตุผล: ยังไม่ทบทวน / ต้องแก้ไข / ทบทวนแล้วสำหรับการเรียนรู้ภายในขอบเขตที่ระบุ

บันทึกชื่อผู้ทบทวน วันที่ เวอร์ชันกฎ และงานที่ยังค้าง หากจะใช้ในงานบริการจริง ต้องมีแผนประเมินและการอนุมัติของหน่วยงานแยกต่างหาก การติ๊กครบในแบบฟอร์มนี้ไม่ใช่การรับรองความแม่นยำทางคลินิก
